# Follow selected object — 1.12.0

A saved checkbox next to the selected-box controls enables perspective camera follow. It starts off. Select a track, enable the checkbox, and orbit or zoom normally. On the next, previous, or jumped-to frame the orbit target moves to the rendered world-space center of the same client-ID track; the last camera offset preserves viewing direction and distance. No native annotation save, selection dispatch, history entry, or keyframe is created.

The adapter waits until Redux frame, canvas model frame (when exposed), and rendered cuboid geometry agree. It waits an additional animation tick before moving the camera, protecting the preserved pose from native scene setup/reset. World centers include parent transforms. Current camera-controls (`getTarget`/`setLookAt`) and OrbitControls-style targets are supported. The source APIs and scene-loading sequence were checked against [CVAT 2.76 canvas source](https://github.com/cvat-ai/cvat/blob/v2.76.0/cvat-canvas3d/src/typescript/canvas3dView.ts).

Following pauses while the track is absent, outside, hidden, while drawing/dragging, or in Free Cam. A transient cleared selection between frames retains the tracked identity. Selecting another track changes the target; selecting a frame-local shape releases it. A job change releases the old identity. Missing orbit APIs disable the checkbox with an explanation. The target is never inferred from position or a server-ID/client-ID collision. Disabling or disposing cancels the follow animation loop. The HUD status explains loading and paused states. Saved preference is restored when a compatible bridge reconnects.

Validation: 106 unit tests and 29 Edge browser tests passed. New tests cover forward/backward/skipped frames, manual orbit and zoom, loading delays, stale rendered geometry, native camera reset, transformed parents, missing/outside/hidden tracks, Free Cam and drawing pauses, selection/job changes, unavailable APIs, disposal, persistent checkbox state, and no annotation edits. Existing Auto-Fit, Auto Adjust, mouse placement, keybind, session and batch tests passed. Extension/demo builds and packaging passed; ZIP contents match source and generated bundles.

Live acceptance on authenticated CVAT remains pending. The browser fixtures exercise real Three.js camera math with a simulated native editor, not real CVAT interpolation or server persistence.
