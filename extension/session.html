Phiên CVAT & Annotation

Đang kiểm tra tab CVAT…

Phiên đăng nhập

Chỉ đọc cookie khi bạn bấm nút. SessionID có quyền truy cập tài khoản; không chia sẻ cho người khác.

Python CLI đi kèm

Python 3.10+, không cần cài package. Tải script, mở terminal trong thư mục chứa script rồi dùng lệnh bên dưới. Trình duyệt không tự chạy Python và không gửi cookie cho tiến trình cục bộ.

Lệnh dùng PowerShell và nhập sessionID/CSRF qua prompt ẩn, không nhúng cookie vào script/lệnh. Có thể dùng biến môi trường CVAT_SESSIONID và CVAT_CSRFTOKEN thay thế. Đổi tên file trong lệnh theo file thực tế.

Import thay thế annotation server: Save rồi đóng editor trước, xác nhận đúng job. CLI tạo và kiểm tra JSON native dự phòng trong cvat-backups trước khi ghi. Restore JSON chỉ hỗ trợ cùng server/job, kiểm tra label/schema attributes; ID annotation trên server có thể đổi. Nạp lại CVAT sau import. Quyền tài khoản vẫn áp dụng, kể cả lỗi export ZIP bị từ chối.

Annotation của job đang mở

Save CVAT trước khi thao tác. Dùng phiên trình duyệt, không cần bấm lấy sessionID. Giới hạn file 8 MiB; file lớn hơn dùng Import/Export native của CVAT.

Job 3D chỉ hiển thị định dạng 3D server hỗ trợ; ưu tiên Datumaro 3D 1.0 (ZIP cuboid/attributes/track_id). Không kèm PCD/ảnh. Export ZIP có thể cần quyền owner/admin tùy server.

JSON native đọc annotation đã Save, giữ cấu trúc tracks/keyframes từ API; có thêm server/job và bảng label ID/tên cơ bản. Không phải bản backup đầy đủ task hoặc định dạng dataset để Upload annotations trực tiếp. JSON chẩn đoán Auto-Fit và preview batch cũng không phải dataset export.

Import có thể thay thế annotation đã lưu của job. Không có Undo native cho thao tác server này. Tool tải bản export dự phòng trước khi upload; giữ file dự phòng để khôi phục thủ công nếu cần.

Trong khi xử lý, giữ tab CVAT ở job hiện tại. Không sửa annotation đến khi nạp lại tab. Nếu trang này đóng, kiểm tra Requests trong CVAT trước khi chạy lại.
