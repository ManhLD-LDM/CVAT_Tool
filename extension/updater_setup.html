Cài updater Windows một lần

Updater tải release GitHub về thư mục cài riêng. Cần Python 3.10+, không cần quyền Administrator.

  1. Tải gói updater từ GitHub Release, giải nén.
  2. Chạy PowerShell trong thư mục vừa giải nén: powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1.
  3. Làm theo installer: Load unpacked thư mục %LOCALAPPDATA%\CVAT-3D-Tool\extension, tắt bản cũ, rồi nhập ID của bản vừa cài.
  4. Reload extension một lần và mở lại CVAT. Từ lần sau dùng nút Reload trên HUD.

ID extension đang mở trang này:

Nếu đang mở bản cũ từ source, ID trên không phải ID của bản cài riêng. Hãy lấy ID sau khi Load unpacked bản cài riêng. Việc chuyển thư mục có thể cần đặt lại preset/phím tắt.

Repo cần có release công khai kèm ZIP extension và checksum. Nếu chưa phát hành, đường dẫn tải sẽ chưa dùng được; có thể dùng gói ZIP do người phát triển cung cấp.
